## 说话要点

- 按一下 → 看到「🎙 录音中…」再开口 → 说完停半秒再按。
- 用中文说功能（"删除命令""完成的事项"），少说英文文件名 / 函数名——平台 ASR 会听错。
- 一句话一个需求。疑问句（"有没有问题"）也会派给 Codex，只读不改。

## 兜底

- 现场网络挂：播放 PPT 里的全流程录屏。
- Codex 慢（qiniu-gpt 流式断连重连）：第 4 步可换成更小的需求，如"把列表里已完成的事项标成绿色"。
