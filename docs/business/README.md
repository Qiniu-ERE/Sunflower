### 结论

- 按现有报价（1k 档缺价的零件按小批量价计），两种型号在建议售价 129.00 / 169.00 USD 下单台贡献为 -47.71 / -25.15 USD，盈亏平衡售价是 190.96 / 201.66 USD。
- 屏显版售价比标准版高 40.00 USD，落地成本只高 8.24 USD。
- 降本先看下面最贵的几项：它们大多只有零售价或小批量价，拿到量产报价前，成本是上界。
- 软件侧每位用户每月语音服务成本 1.64 USD，订阅价 2.99 USD；Codex 的费用由用户自己的账号承担，不进设备成本。

## 口径

- **报价 / 假设分开记**：`bom.csv`、`rates.csv` 的 `kind` 列标明每个数字是报价（附链接与查询日）还是假设。查询日是 2026-10-23。
- **1k 价是上界**：没查到 1k 档时，按 1k 以下能查到的最大批量档计；连批量档也没有的，按零售价计。说明写在 `note` 列。
- **不计团队人力**：固件、App、主机软件的开发人力都不在 NRE 里。
- **语音服务按灵矽标准时长计**：灵矽按「会话时长 ×（1 + 大模型系数 + 音色系数）」扣资源包（[计费说明](https://linx.qiniu.com/docs/xrobot/billing/resource-usage-billing)）。所选模型和音色的系数没查到，暂按 1.0 计。资源包价格从账号内的商品接口读取：100 小时 300 元，1000 小时 2000 元，10000 小时 16000 元，有效期都是 1 年。
- **Codex 单价是参考值**：用户用自己的 ChatGPT 订阅（Plus 20 USD/月起，含 Codex CLI）或 API Key 付费，不进设备成本。表里按 OpenAI gpt-6.1-sol 刊例价（[pricing](https://developers.openai.com/api/docs/pricing)），乘以 `codex_usage.csv` 里本机实跑 7 次任务的用量；七牛渠道的 GPT 售价没有公开页面。
- **语音自建对照**：如果不用灵矽、改用公有云 ASR / TTS，单价参考如下：
  - 腾讯实时 ASR：3.20 元/小时（[来源](https://cloud.tencent.com/document/product/1093/35686)）
  - 腾讯大模型 TTS：1.2 元/万字符（[来源](https://cloud.tencent.com/document/product/1073/34112)）
  - 阿里 paraformer-realtime-v2：约 0.86 元/小时（[来源](https://help.aliyun.com/zh/model-studio/paraformer-realtime-v2)）

  灵矽 1000 小时包折合 2 元/小时，而且已经包含对话大模型。

## 数据缺口

- **没有 1k 报价**：电机、XVF3800、两块圆屏、轴承，以及贴片总价。
- **查询时库存为 0**：第二颗 ESP32-S3、WS2812B-2020、AS5600、CH224K 四个立创料号。
- **没有模组外的实际报价**：PCB、注塑件、组装人工、关税与头程都是假设。
- **亚马逊费率**：取自第三方汇总，没有在 Seller Central 核对。
- **灵矽计费系数**：大模型和音色的计时系数未知。
- **其他认证**：CCC 是否适用未查到；所有认证费用都是检测机构或咨询公司的估价，不是正式报价。
