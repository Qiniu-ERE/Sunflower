### 结论

- 按现有报价（1k 档缺价的零件按小批量价计），两种型号在亚马逊建议售价 299.00 / 349.00 USD 下单台贡献 101.55 / 113.21 USD，盈亏平衡售价 167.12 / 201.98 USD。
- 众筹按筹款额提成的费用合计 31%（平台、支付、投放、售后），亚马逊是 23%；众筹的盈亏平衡价 194.00 / 232.90 USD，比亚马逊高。众筹的价值在资金流：支持者先付款，NRE 和首批备货不用先垫，也顺带验证需求。
- 按早鸟价 249.00 / 289.00 USD，开模方案要 619 / 710 名支持者才收回 NRE；自己 FDM 打印 + 自己组装要 338 / 330 名。Kickstarter 上同类先例的支持者数：ESP32 Agent Dev Kit 170、Ropet KAMOMO 1,134、Living.ai EMO 2,126、Loona 7,811、Anki Vector 8,300。
- 早鸟价比亚马逊售价低 17% / 17%，先例的早鸟折扣在 20%–54%：早鸟价不能低于众筹盈亏平衡价，折扣只能给得比先例小。
- 屏显版售价比标准版高 50.00 USD，落地成本只高 26.84 USD。
- 把查到国内价的 2 项换成国内价后，亚马逊盈亏平衡价是 169.16 / 204.02 USD；没查到国内价的零件仍按海外价计。
- 软件侧每位用户每月语音服务成本 1.64 USD，订阅价 2.99 USD；Codex 的费用由用户自己的账号承担，不进设备成本。

## 和竞品的差别

- **重叠最多的是 Rabbit R1**：官方支持页写明，R1 可以用语音控制电脑上的 Claude Code CLI、Hermes Agent 和 OpenClaw（[来源](https://www.rabbit.tech/support/article/claude-code-on-rabbit-r1)）。电脑上要装 rabbit agent，API Key 由用户自己提供。Codex 不在它的语音控制名单里。R1 售价 199 USD，比太阳花两种型号都便宜。
- **太阳花在做的事**：
  - 语音派活之后，Codex 在本机后台执行，每个任务留一个 `voice:` 提交，可以语音撤销。
  - 任意浏览器都能打开进展面板。
  - 做完以后由设备主动播报结果。
  - 4 麦定向加云台电机，可以转向说话的人。表里 11 款产品中，官方写明会转向说话人的只有 Loona。
  - 主机软件和固件以 MIT 协议开源。
- **还没验证的**：R1 对 Claude Code 的会话是怎么呈现、怎么播报的，官方页面没写细节，所以表里只记「是」，不做优劣比较。

## 口径

- **采购与物流口径**：在中国组装，出口到美国销售。「海外报价」用各分销商面向海外的美元价：立创 LCSC、iFlight 在深圳，Digikey 用的是墨西哥站（美元计价），轴承用的是澳洲零售价。「国内采购」只替换查到了国内价的几项（都来自得捷中国），价格含 13% 增值税；出口退税没有扣，所以 XVF3800 的国内价反而更高。电机、喇叭、2.1″ 无触摸圆屏的国内价没查到；立创商城国内站访问被拦。`landed_share` 是从中国到美国仓的头程运费加美国进口关税。
- **报价 / 假设分开记**：`bom.csv`、`rates.csv` 的 `kind` 列标明每个数字是报价（附链接与查询日）还是假设。查询日是 2026-10-23。
- **1k 价是上界**：没查到 1k 档时，按 1k 以下能查到的最大批量档计；连批量档也没有的，按零售价计。说明写在 `note` 列。
- **不计团队人力**：固件、App、主机软件的开发人力都不在 NRE 里。
- **语音服务按灵矽标准时长计**：灵矽按「会话时长 ×（1 + 大模型系数 + 音色系数）」扣资源包（[计费说明](https://linx.qiniu.com/docs/xrobot/billing/resource-usage-billing)）。所选模型和音色的系数没查到，暂按 1.0 计。资源包价格从账号内的商品接口读取：100 小时 300 元，1000 小时 2000 元，10000 小时 16000 元，有效期都是 1 年。
- **Codex 单价是参考值**：用户用自己的 ChatGPT 订阅（Plus 20 USD/月起，含 Codex CLI）或 API Key 付费，不进设备成本。表里按 OpenAI gpt-6.1-sol 刊例价（[pricing](https://developers.openai.com/api/docs/pricing)），乘以 `codex_usage.csv` 里本机实跑 7 次任务的用量；七牛渠道的 GPT 售价没有公开页面。
- **语音自建对照**：如果不用灵矽、改用公有云 ASR / TTS，单价参考如下：
  - 腾讯实时 ASR：3.20 元/小时（[来源](https://cloud.tencent.com/document/product/1093/35686)）
  - 腾讯大模型 TTS：1.2 元/万字符（[来源](https://cloud.tencent.com/document/product/1073/34112)）
  - 阿里 paraformer-realtime-v2：约 0.86 元/小时（[来源](https://help.aliyun.com/zh/model-studio/paraformer-realtime-v2)）

  灵矽 1000 小时包折合 2 元/小时，而且已经包含对话大模型。
