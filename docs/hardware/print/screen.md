# 太阳花 · 屏显版 3D 打印原型

![屏显版效果图：左为装配，右为爆炸图](render-screen.jpg)

<sub>左：装好的样子（花芯是执行中的进展画面示意，透明面罩没画）。右：爆炸图，花头沿视线方向拆开，底座沿花茎拆开。</sub>

这套文件用来打一台**外观和装配原型**：花盆、土面、叶片、花头外壳都能装起来，花头可以用手转动，2.1″ 圆屏、透明面罩、花瓣灯和瓢虫键都有安装位。和[标准版](standard.md)相比，底座、花茎和叶片完全相同，只换花头的 4 个零件。电机、麦克风板、主板等电子件没有建模（见文末「没覆盖的」）。

- 任何 FDM 打印机都能打。最大的零件是 105 × 105 × 64 mm，床面 ≥ 120 × 120 mm 即可。
- 所有零件按表里的姿态摆放，**都不需要支撑**。
- 文件**还没实际打印验证过**，第一次打印先核对配合尺寸。

**打印参数**：PLA 或 PETG，0.4 mm 喷嘴，层高 0.2 mm，3 圈墙，填充 15–20%，不加支撑。

- 花瓣环用半透明耗材，背后的灯才透得出来。
- 叶片很薄，建议加 3 mm brim。
- 所有零件的实体体积合计 157 cm³。按 100% 填充的 PLA 算约 195 g，这是用料的上限。

## 装配

1. **底座**：用 4 颗螺丝把底板从下往上拧进花盆的 4 个螺柱。装扬声器的话，先把扬声器朝下粘在底板中间。
2. **格栅**：把 6801 轴承从格栅底面压进轴承座，外圈顶到唇口为止。把格栅土面朝上放进花盆口沿，它会落在内沿上。
3. **花茎**：
   - 铝管从上往下穿过轴承，让底端停在土面下 26 mm。
   - 两个卡圈分别贴住轴承内圈的上、下两面，用胶粘在铝管上。
   - 粘好后花茎只能转，不能上下窜。
4. **叶片**：
   - 叶托套在铝管上，让底面高出土面 22 mm，粘牢。
   - 两片叶子的插舌各插进一个斜插槽，粘牢。
   - 开关放进右叶的键座，引线穿过键座底部的孔，沿叶背的槽走到叶托。线要穿进铝管的话，自己在管壁上钻一个孔。
   - 瓢虫键帽粘在开关按柱上。
5. **花头**：
   - 灯珠（可选）按进前框的灯珠槽，从背面串焊。
   - 圆屏从正面放进屏槽，排线舌朝下，排线穿过过孔进腔。
   - 3 根销钉插进前框的销孔，再把花瓣环对准销钉压上去。
   - 脸盖从正面塞进花瓣环中间，压住圆屏，用胶点牢。透明面罩放进脸盖正面的沉台，在边上点胶。
   - 主控板固定在后壳腔内，接好圆屏和灯珠。过颈座的线只有 4 芯（5 V、GND、按键 × 2）。
   - 走好线后，把后壳的唇口按进前框背面的环槽，粘牢。
6. **装头**：把铝管顶端插进后壳的颈座孔，插到底，深 16 mm。花头自然朝前、上仰 20°。

**配合尺寸**：

- 插配一律单边留 0.2 mm。
- 轴承座 Ø21.1，压配。
- 颈座孔和叶托孔是 Ø12.3。
- 销孔 Ø1.95，配 1.75 mm 耗材。
- 打紧了先用钻头或砂纸修孔，不要改缩放比例。

## 自检

[`check.md`](check.md) 由 `model.py` 生成，每次重新生成时一起更新：

- 每个零件都是单个连通体；另用一段不依赖建模库的脚本逐个读 STL 核过：每条边恰好被两个三角形共用，没有退化三角形。
- 13 件打印件和外购件（铝管、轴承、圆屏、面罩、灯珠、开关、扬声器）两两求交，重叠体积都不超过 0.5 mm³。
- 整机高 231 mm。

**悬空**：

- 只有后壳的颈座孔是斜的（约 199 mm²），孔顶可能轻微下垂。插管前用 Ø12 钻头过一遍。
- 前框的灯珠槽和圆屏槽要桥接，最大跨度 Ø10.4。

## 没覆盖的、待核实的

- **电机和电子件**：云台电机、联轴器、磁编码器、环形麦克风板、两块主控板和配重都没有建模。铝管底端在土面下 26 mm 悬空，留给电机联轴器；原型先手转。
- **外购件的厚度和按柱尺寸是占位值**：2.1″ 屏的厚度、排线舌宽度、面罩、灯珠板、开关按柱都在 `model.py` 的 `BUY` 里标了 `*`，拿到实物先量一下。
- **屏的外形**：数据表只给了外形 58.18 × 60.71，这里按「Ø58.18 圆加下方排线舌」建模。如果舌更宽，屏槽的两个下角离最近的两颗灯珠槽只有约 1 mm，改 `BUY["st7701s"]` 时要看一眼 `check.md` 的干涉结果。
- **土面边缘有一圈窄缝**：盆口往上收，格栅必须比口沿最窄处小才放得进去，所以土面边缘和盆壁之间有约 0.5 mm 的缝。
- **整机高度比概念图矮 4 mm**：概念图标的是约 235，这里是 231（花瓣环 Ø105、脸心高 182 mm、上仰 20°，都按概念图）。

## 改尺寸、重新生成

```bash
python3 -m venv .venv && .venv/bin/pip install manifold3d                              # 只有重新生成时需要
.venv/bin/python docs/hardware/print/model.py docs/hardware/print                     # 写 stl/ 和 check.md
.venv/bin/python docs/hardware/print/model.py docs/hardware/print --scene /tmp/scene  # 效果图场景
swift docs/hardware/print/render.swift /tmp/scene/screen /tmp/hero.png hero          # 渲染，仅 macOS
swift docs/hardware/print/render.swift /tmp/scene/screen-exploded /tmp/explode.png explode  # 爆炸图
```

`render-screen.jpg`（1640×900）是这两张 1600×1200 的图左右拼起来再裁的：左边整机，右边爆炸图。拼接没有脚本，重新出图时对照现有那张手工对齐。

尺寸都在 `model.py` 顶部：外购件在 `BUY`，两种型号的差异在 `VARIANTS`。`manifold3d` 只是生成工具，不进 `requirements.txt`。
